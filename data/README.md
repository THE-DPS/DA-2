# Data directory

`sample_reviews.csv` is a tiny, synthetic dataset intended only to smoke-test the code. It must not be used to report meaningful model performance.

For actual experiments, obtain a properly licensed, representative dataset and place a processed CSV with columns `text` and `label` here. Document source URL, license, version, access date, label mapping, exclusions, and preprocessing decisions. Do not commit data unless its license permits redistribution and doing so is appropriate.
